# PCP 1.2.0 — Admin Panel Separation

- Admin panels separated into Overview, Website Status, Community Profile, Forms, Operations, Responses.
- Website state simplified to LIVE and MAINTENANCE.
- Maintenance activation supports optional end estimate. Empty estimate displays “Waktu maintenance tidak ditentukan.”
- Maintenance does not auto-expire; only clicking LIVE releases the website again.
- Public homepage redirects only when maintenance is active.
